# L4D2FilterTool

用于按服务器名称、IP 或网络端点拦截目标，并可将目标从 Steam 组服列表中隐藏。

## 下载与启动

1. 从 [Releases](https://github.com/reimuandmarisa/L4D2FilterTool/releases/latest) 下载当前版本的 ZIP。
2. 将 ZIP **完整解压**到本地文件夹，不要单独移动 `FilterTool.exe`；请保留随包提供的 WinDivert 依赖文件。
3. 右键 `FilterTool.exe`，选择“以管理员身份运行”。首次启动或修改拦截状态时按 Windows 提示授权。

## 图形界面

### ① 添加拦截目标

1. 输入目标后点击「添加并拦截」（输入 IP 或端口时，按钮会显示对应操作）。支持以下输入：
   - **服务器名称**：数字自动匹配同系列编号（如 01、02），其他文字区分大小写；
   - **IP 地址**：按地址匹配，例如 `1.2.3.4`；
   - **端点**：按地址和端口匹配，例如 `1.2.3.4:27015`；
   - **子网**：按 CIDR 网段匹配，例如 `1.2.3.0/24`。
2. 需要让目标同时从 Steam 组服列表消失时，勾选「同时从组服列表隐藏」。不需要解析名称对应 IP 时，勾选「本次不查找 IP」。
3. 名称、IP、端点和子网可以分别添加；请按实际需要选择精确地址或网段，避免误拦截。

### ② 拦截清单

查看已保存的名称与地址规则。选中后点击「删除所选」移除目标；「清空全部规则…」会先确认并自动备份。支持 Ctrl / Shift 多选、双击复制。清单表示规则已经保存，是否正在生效请查看运行状态。

### ③ IP 候选

这里显示名称解析或运行中发现的 IP 候选。确认属于目标服务器后再加入拦截清单；不确定时不要批量选择整个网段。

### ④ 运行状态与工具

- **已配置**表示规则已经保存；**运行中**才表示当前拦截正在工作。两者不是同一个状态。
- 需要登录 Windows 后自动开始拦截时，启用「登录 Windows 后自动拦截」。
- 图形界面会执行本窗口的拦截；关闭时会提示是否停止。需要关闭窗口后仍继续拦截，请另行运行 `FilterTool.exe --run`。勾选「登录 Windows 后自动拦截」用于下次登录，不代表当前已启动常驻进程。可用 `--status` 确认。

### 组服列表重复名称过滤

「Steam 组战役模式服务器」列表里经常有多个服务器使用相同的显示名，或者只有末尾的 `#编号` 不同。该功能默认开启：在同一遍列表重建中，这些行只保留第一条，后面的同名行不再出现；开始下一遍重建时会重新计数，不会把下一遍列表清空。

- 同名判断会忽略开头的 UTF-8 BOM 和末尾的 `#数字` 后缀（如 `#90`、`#85`、`#73` 视为同一台）；其余部分区分大小写；名字为空的行不参与去重。
- 游戏有时会在一次刷新里连续重建列表好几遍，并在每遍开始前清空可见行；工具检测到“同一遍的前两个名字再次成对出现”时就会重新计数，避免把最后一遍整页跳过。
- 图形界面 ④ 区的「组服列表去重（同名只留一条）」可以随时开关。
- 命令行：`FilterTool.exe --group-filter dedupe on|off`；`FilterTool.exe --group-filter status` 可查看当前状态。
- 想临时对比过滤前后差异，可先执行 `FilterTool.exe --group-filter passthrough on` 放行全部行。

### 按名字拦截与共享 IP

按服务器名添加拦截时，工具会先查这个名字对应的地址。如果同一个 IP 上还出现过其它服名（共享 IP），不会再封整个 IP，而是只封这个名字实际使用的 `ip:端口`，避免同 IP 的其它服务器被一起误拦；独占 IP 仍按整个 IP 拦截。

- 这个规则只作用于“按名字解析”自动生成的条目；手动添加的 IP、端点和网段，仍严格按你填写的范围生效。
- 旧版本可能已经把共享 IP 写成了裸 IP 条目。新版本启动时会自动改成精确端口，命令行会提示“共享 IP 精确拦截”或修复结果。
- 想确认某个名字到底封了哪些地址，可查看 `ip_block.txt` 里的 `ip:端口` 条目，或运行 `FilterTool.exe --status`。

## 常用命令

在包含 `FilterTool.exe` 的文件夹中，以管理员身份打开终端运行：

```text
FilterTool.exe --run                 常驻拦截
FilterTool.exe --add <名称或IP>       添加目标并拦截
FilterTool.exe --status              查看已配置与运行状态
FilterTool.exe --group-filter dedupe on|off  开关组服列表同名去重（默认 on）
FilterTool.exe --help                查看当前版本的完整命令
```

## 排障

- 状态显示“已配置”但不是“运行中”：确认终端或程序以管理员身份运行，重新启动 `FilterTool.exe`，再运行 `FilterTool.exe --status`；需要常驻时运行 `FilterTool.exe --run`。
- 程序提示缺少 WinDivert、启动失败或拦截无效：确认 ZIP 已完整解压，依赖文件仍与 `FilterTool.exe` 位于随包要求的位置，并检查 Windows 安全软件是否阻止了程序。
- 组服列表功能提示游戏版本或组件版本不匹配：这是保护性拒绝。请更新游戏或工具到匹配版本，**不要强行绕过检查**。
